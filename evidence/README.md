# Historical execution receipts

These files record software builds, diagnostic runs, retail observations, and benchmarks
of the supplied starter. Their embedded revisions, commands, input identities, and
toolchain versions define their scope. They are not physical hardware captures or a
description of the current checkout.

`input-provenance.json` preserves the supplied images and compiler artifact identities.
`next-revision/` contains the subsequent starter revision's receipts. Run the commands
in [TESTING](../docs/TESTING.md) to check the current source.
