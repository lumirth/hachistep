# Artwork

`glyph.svg`, `logo.svg`, and `logo-stacked.svg` are the current brand artwork. The other logo SVGs retain alternate compositions and colors.

`icons/` contains platform artwork, Apple editing layers, and native resources. Desktop builds use `macos/icon.png`, `macos/icon.icns`, and `windows/icon.ico`. The other platform and appearance resources are retained for future use.
